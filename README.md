# 资产罗盘 · Asset Compass

供个人在本机使用的人民币资产观察台。总览比较关注资产的区间表现，详情按标的展示行情、观察公式和可回看的历史结果。技术栈为 Vue 3、Nuxt、TypeScript、Node.js 和 SQLite。

## 运行

使用 Node.js 22.19 或更高的 22.x 版本。在仓库目录运行以下命令，然后打开终端显示的本地地址。

```sh
npm ci
npm run dev
```

也可构建后单独运行 Node 服务。

```sh
npm run typecheck
npm test
npm run build
npm start
```

默认只监听本机回环地址。通过环境变量 `PORT` 可设置生产服务端口。行情保存在 `.data/compass.sqlite`，可用 `ASSET_COMPASS_DATA_DIR` 更换目录。关注列表、焦点标的和仓位测算输入保存在当前浏览器的本地存储中。

## 数据

| 用途 | 来源与口径 |
| --- | --- |
| 国内黄金 | 上金所 Au99.99 日线收盘价，人民币元/克。延时分时沿用交易所时标；若返回未来时标或无有效分钟，显示缺数。 |
| 场外基金 | 天天基金披露的单位净值及日增长率。默认关注摩根纳斯达克100人民币 A（019172）和摩根标普500人民币 A（017641）。添加面板也支持标普500人民币 C（019305）及按六位代码添加其他基金。 |
| 黄金策略 | SPDR Gold Shares 官方历史档案中的 GLD 美元收盘价，FRED 的 DGS6MO、DGS1、DGS2 和 DFF。GLD 含基金费用及跟踪误差。 |

数据无需密钥。海外来源可使用 `ASSET_COMPASS_PROXY` 指定 HTTP 代理，其次读取 `HTTPS_PROXY` 或 macOS 系统 HTTPS 代理。设置空的 `ASSET_COMPASS_PROXY` 将直接连接海外来源。

服务运行时，每小时检查默认标的和黄金模型的缓存。日线缓存有效期 4 小时，美国数据 6 小时；打开页面时也会读取已关注标的，分时缓存 1 分钟。点击刷新可以重新拉取。来源异常时保留已有快照并显示提示。各标的按自己的最近观测日展示，基金详情显示净值归属日，盘中无法得到当日最终 QDII 净值。

## 图表与黄金三支箭

总览跨资产图对齐共同观测日并以同一天为起点，关注列表按各自最近披露日计算。基金涨幅按每日披露的净值增长率连乘，来源缺少该字段时退回相邻单位净值计算。详情的净值曲线展示原始单位净值。关注列表波动率使用最近 60 个日收益的样本标准差乘以 √252。

黄金详情左轴为国内金价，右轴为模型目标仓位。拖动日期滑杆或在图中定位，公式、三项输入和仓位一起变化。

1. **动量**。比较 GLD 过去 6 个、12 个日历月的累计收益与同期美国国债基准，每项严格跑赢得 0.5 分。锚点用对应日期或此前最近交易日。国债期间收益按起点年化收益率 × 实际天数 ÷ 365 近似。
2. **美联储信号**。取 2 年期美债收益率与已可用有效联邦基金利率之差，最近 20 个美债观测日的平均差小于零得 1 分。DFF 使用严格早于该美国交易日的观测值。
3. **波动率系数**。GLD 简单日收益的指数加权样本标准差乘以 √252。权重质心为 60 个交易日，衰减因子为 60/61，至少需要 60 个日收益。系数取 15% ÷ 年化波动率与 1 的较小值。
4. **目标仓位**。目标仓位 =（动量得分 + 美联储得分）÷ 2 × 波动率系数，取值 0% 至 100%。国内收盘日只挂接更早的美国日期；超过 7 天的旧美国观测不挂接。历史值采用来源当前提供的历史序列，未保存各次宏观修订前的独立版本。

策略资金填 10,000 元，若某一观察日目标仓位为 23.33%，对应的黄金持仓市值约为 2,333 元。在「查看计算依据与调仓差额」填入已有黄金市值，可以查看目标与持仓的差额。此百分比仅应用于划给该策略的资金。

行情来源和归属可在详情页查看。仓库不包含行情数据文件，公开转播或分发前需另行核对来源授权。
